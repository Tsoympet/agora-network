# Community growth programs

**Maturity:** Scaffold.

## Agora Academy

Free blockchain courses; developer / miner / validator / merchant / governance education; Greek and English materials; university partnerships.

## Agora Builder Guild

Developer directory, mentorship, team matching, testnet assets, templates, office hours, code review, security review. Funded primarily from the OVL Builder Treasury when live.

## Agora Merchant Network

See [`MERCHANT_NETWORK.md`](MERCHANT_NETWORK.md).

## Agora Node Guild

Home RandomX miners, full/archival nodes, OVL validators, DRC validators, RPC providers, seeders, explorers. Publish uptime, stake concentration, hash-rate concentration where measurable, geographic concentration, infrastructure diversity, delegation concentration.

## Agora Events

Monthly community calls; weekly developer office hours; local meetups; quarterly hackathons; annual Agora Summit in Greece; university competitions; merchant demonstrations; governance review sessions.

## Official interfaces (planned scaffolds)

Passport, Forum, Assembly voting, Treasury dashboard, Grants portal, Bounty/Missions marketplace, Hub directory, Developer directory, Miner/Validator directory, Merchant map, Event calendar, Proposal discussion, Delegate profiles, Voting history, Grant milestone tracking, Public financial reports, Contribution reputation.

Discussion may be off-chain; proposal creation, votes, grant approvals, treasury payments, milestone acceptance, hub accreditation, and governance execution should be cryptographically auditable.
