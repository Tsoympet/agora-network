# Agora Merchant Network

**Maturity:** Scaffold. Settles in native **DRC** (and may sponsor TLT base fees via wallets/apps).

## Capabilities

QR payments, payment links, invoices, tips, membership subscriptions, event tickets, loyalty rewards, local discounts, escrow, merchant directory / map.

## Protocol anchors

- DRC payment module (destination tags, invoices, escrow)
- Hub directory for local merchant cohorts
- Fee sponsorship without consensus price oracles

## Related programs

- **Agora Academy** — merchant onboarding courses  
- **Agora Events** — merchant demonstrations  
- **Passport** — merchant onboarding attestations
