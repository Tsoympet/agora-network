# Grants and Missions

**Maturity:** Scaffold.

## Funding mechanisms

1. **Microgrants** — small/fast: meetups, translations, tutorials, testing, minor tools.  
2. **Milestone grants** — public proposal → review → milestone agreement → partial payment → public deliverable → acceptance test → final payment.  
3. **Bounties and RFPs** — protocol publishes tasks; contributors claim; public review.  
4. **Retroactive public-goods rewards** — demonstrated impact; evidence; public evaluation; anti self-dealing.

## Agora Missions

Task types: code, documentation, translation, testing, design, event organization, research, merchant onboarding, security reporting.

Completion may create Passport attestations and may distribute OVL or DRC rewards from the appropriate treasury under governance rules.

## Auditable on-chain (or cryptographically logged)

Proposal creation, votes, grant approvals, treasury payments, milestone acceptance — even if discussion is off-chain.

The canonical scaffold validates ordered milestone evidence and Mission
lifecycle transitions and commits records in the community root. These records
do not move treasury funds until signed consensus disbursement is implemented.
