# SLIP-0044 registration (mainnet prep)

Agora wallets derive keys at `m/44'/8888'/account'/change/index`.  
`8888` is a **provisional** coin type until SLIP-0044 assigns a permanent code.

## Why this matters

- Hardware wallets and custodians key off the registered coin type
- Changing coin type after mainnet launch splits address space / funds risk
- Genesis `wallet.coin_type` must match the registered value at freeze

## Current state

| Field | Value |
| --- | --- |
| Constant | `AGORA_COIN_TYPE = 8888` (`agora-crypto`, light-client) |
| Status | `provisional-slip44-pending` (genesis `wallet.coin_type_status`) |
| Networks | mainnet / testnet / dev all use `8888` until registration |

## Registration checklist

1. Open a PR against [satoshilabs/slips](https://github.com/satoshilabs/slips) `slip-0044.md`
2. Propose an unused coin type and document:
   - Coin: Agora Network (TLT)
   - URL: project site / GitHub
   - Status: reserved / allocated
3. Land the slip merge; record the assigned number
4. Update in one coordinated release (before mainnet genesis freeze):
   - `core/crates/crypto/src/bip44.rs` → `AGORA_COIN_TYPE`
   - `apps/shared/light-client/wallet.ts`
   - `docs/genesis/mainnet.genesis.json` → `wallet.coin_type` + `coin_type_status: registered`
   - `docs/genesis/testnet.genesis.json` (optional — testnet may keep `8888` or follow BIP44 testnet `1`)
5. Re-derive any published faucet / premine keys if coin type changes
6. Freeze mainnet genesis only **after** step 4

## Do not

- Ship mainnet with `provisional-slip44-pending` without a public registration plan
- Change coin type after users hold mainnet funds
- Invent a multi-asset L1 to “solve” ticker branding — TLT remains the sole L1 UTXO asset
